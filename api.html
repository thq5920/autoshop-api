AutoShop 接口文档

专门用于接口自动化测试练习的 Mock 商城 API，共 13 个接口，支持 JWT 认证、Mock 支付三态（SUCCESS / FAIL / PENDING）、多语言（zh-CN / en-US）。

Base URL: http://localhost:8000/api/v1  |  Swagger: http://localhost:8000/docs  |  i18n: Accept-Language: en-US 或 ?lang=en-US

认证 Auth

POST

/auth/register

无需鉴权

注册新用户。用户名、邮箱全局唯一，手机号可选。密码自动 bcrypt 哈希存储。

请求参数
字段类型必填说明
usernamestring必填4~20 位，字母/数字/下划线，唯一
passwordstring必填8~20 位
emailstring必填标准邮箱格式，唯一
phonestring?否11 位手机号（1 开头，格式 1[3-9]xxxxxxxxx）
请求示例
{
  "username": "alice",
  "password": "Test@123456",
  "email":    "alice@example.com",
  "phone":    "13800138000"
}
响应 200
字段类型说明
data.userIdint新用户 ID
data.usernamestring用户名
成功响应
{
  "code":    200,
  "message": "成功",
  "data": { "userId": 1, "username": "alice" },
  "timestamp": 1787886000000,
  "requestId": "req_register_1"
}
错误码
HTTP业务码场景
42240202username 少于 4 位
42240205password 少于 8 位
42240207email 格式错误
42240209phone 格式错误
40940901用户名已被占用
40940902邮箱已被注册
POST

/auth/login

无需鉴权

用户名 + 密码登录，返回 JWT Bearer Token，有效期 2 小时（7200 秒）。

请求参数
字段类型必填说明
usernamestring必填
passwordstring必填
请求示例
{
  "username": "alice",
  "password": "Test@123456"
}
响应 200
字段类型说明
data.accessTokenstringJWT Token，后续请求 Authorization: Bearer {token}
data.tokenTypestring固定 "Bearer"
data.expiresInint7200（秒）
data.userIdint用户 ID
成功响应
{
  "code":    200,
  "message": "成功",
  "data": {
    "accessToken": "eyJhbGciOiJIUzI1NiJ9...",
    "tokenType":   "Bearer",
    "expiresIn":    7200,
    "userId":      1
  },
  "timestamp": 1787886000000,
  "requestId": "req_login_1"
}
错误码（注意：code 受 EXPOSE_AUTH_DETAIL 影响）
HTTP业务码条件说明
40140301EXPOSE_AUTH_DETAIL=true账号不存在
40140302EXPOSE_AUTH_DETAIL=true密码错误
40140303EXPOSE_AUTH_DETAIL=false（生产默认）用户名或密码错误（防枚举）
i18n 示例：请求头 Accept-Language: en-US 可将 message 切换为英文，如 "Account does not exist"。

订单 Orders

POST

/orders

需鉴权

将购物车项结算为订单（Mock 支付）。下单后自动从购物车删除对应项并扣减商品库存。收货人手机号格式 1[3-9]xxxxxxxxx，地址 1~200 字符。

请求参数（Body）
字段类型必填说明
cartItemIdsint[]必填购物车项 ID 列表，至少 1 个
receiverobject必填收货人信息
receiver.namestring必填收货人姓名，1~50 字符
receiver.phonestring必填手机号，11 位，1[3-9] 开头
receiver.addressstring必填详细地址，1~200 字符
remarkstring?否订单备注，最多 200 字符
mockResultstring?否支付模拟结果：SUCCESS（默认）/ FAIL / PENDING
请求示例
{
  "cartItemIds": [80001],
  "receiver": {
    "name":    "张三",
    "phone":   "13800138000",
    "address": "上海市浦东新区测试路 100 号"
  },
  "remark":    "接口自动化测试订单",
  "mockResult": "SUCCESS"
}
响应 200（data 字段）
字段类型说明
data.orderIdint订单 ID
data.orderNostring订单号，格式 MOCK{YYYYMMDDHHMMSS}{userId:04d}
data.orderStatusstringPAID / PAY_FAILED / PENDING_PAYMENT
data.paymentStatusstringMOCK_SUCCESS / MOCK_FAILED / MOCK_PENDING
data.totalAmountfloat订单总金额
data.createdAtstringISO 8601 时间
Mock 结果对照表
mockResult 参数orderStatuspaymentStatus
SUCCESS（默认）PAIDMOCK_SUCCESS
FAILPAY_FAILEDMOCK_FAILED
PENDINGPENDING_PAYMENTMOCK_PENDING
错误码
HTTP业务码场景
40040602cartItemIds 为空
40440601购物车项不存在（不属于当前用户）
40040502商品已下架
40040503库存不足

测试工具 Test Only

POST

/_test/reset

无需鉴权 双开关

测试环境唯一的数据重置入口。TRUNCATE 5 张表 + 重新灌入 scripts/mock_data.sql 的固定 mock 数据（5 × 100 条），末尾 12 条 SELECT 检查保证无孤儿记录、订单/明细金额一致。 接口底层调用 app.test_data.reset_test_data()；api_tests.common.db_manager 也委托同一函数，禁止另行实现 reset/seed。

挂载条件（两个开关同时满足才注册此路由）：
环境变量取值默认值
AUTOSHOP_ENVtestdev
AUTOSHOP_ENABLE_TEST_APItruefalse

任一条件不满足 → 路由不被注册，请求返回 404（非 403，便于区分"未启用 / URL 错误"）。

启用方式：cp .env.test.example .env

核心演示商品（reset 恢复，覆盖 4 类测试场景）
productIdnamepricestockstatus测试场景

1002iPhone 17 Pro7999.0086ON_SALE✅ 正常商品
1003iPhone 17 Pro Max9999.000ON_SALE⚠️ 库存不足 → 40503 INSUFFICIENT_STOCK
1004Samsung Galaxy S265499.0010OFF_SHELF🚫 商品下架 → 40502 PRODUCT_OFF_SHELF（仅在创建订单时拦截）
完整数据：scripts/mock_data.sql 一次性写入 5 × 100 条固定 mock 数据， 直接 mysql -u autoshop -p autoshop < scripts/mock_data.sql 等价于此接口。 历史库若带物理外键，请先跑 python scripts/migrate_database.py（幂等，删 FK + 补逻辑 FK 索引）。
