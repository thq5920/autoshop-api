AutoShop 数据库说明

AutoShop API 使用 MySQL 8.0 作为数据存储，基于 SQLAlchemy 2.0 ORM 实现。数据库包含 5 张核心业务表，支持用户认证、商品管理、购物车和订单处理。

数据库概览

5 张数据表一览

👤 users（用户表）
📦 products（商品表）
🛒 cart_items（购物车）
📋 orders（订单主表）
📝 order_items（订单项）
技术栈：MySQL 8.0 + SQLAlchemy 2.0 + PyMySQL
字符集：utf8mb4（支持完整 emoji 和多语言）
排序规则：utf8mb4_unicode_ci

数据完整性由应用层业务代码和自动化测试保证，各表均可独立 TRUNCATE / DELETE，不会有外键约束报错。

users 用户表

TABLE

users

存储用户账户信息，密码以 bcrypt 哈希存储。username 和 email 全局唯一。
字段名 类型 约束 说明
id INT PK AUTO_INCREMENT 用户 ID，自增主键
username VARCHAR(20) UNIQUE INDEX NOT NULL 登录用户名，4~20 位字母/数字/下划线
password_hash VARCHAR(128) NOT NULL bcrypt 哈希后的密码
email VARCHAR(120) UNIQUE INDEX NOT NULL 邮箱，全局唯一
phone VARCHAR(20) NULL 手机号，可选，11 位（1[3-9]开头）
nickname VARCHAR(50) NULL 昵称，可选
created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP 注册时间，UTC 时区
索引说明：username 和 email 建立唯一索引，支持快速查找和注册时的唯一性校验。

products 商品表

TABLE

products

存储商品信息。金额字段使用 DECIMAL(10,2) 确保精度。status 控制上下架，stock 控制库存。
字段名 类型 约束 说明
id INT PK AUTO_INCREMENT 商品 ID，自增主键
name VARCHAR(100) NOT NULL 商品名称
description VARCHAR(500) NULL DEFAULT 'AutoShop Test Product' 商品描述
category VARCHAR(50) INDEX NOT NULL 商品分类，如 phone/laptop/earphones
price DECIMAL(10,2) NOT NULL 单价（元），最高 99999999.99
stock INT NOT NULL DEFAULT 0 库存数量，下单时扣减
status VARCHAR(20) NOT NULL DEFAULT 'ON_SALE' ON_SALE（在售）/ OFF_SHELF（下架）
金额精度：使用 DECIMAL(10,2) 而非 FLOAT 或 DOUBLE，避免浮点数精度问题。

cart_items 购物车明细表

TABLE

cart_items

存储用户的购物车项。同用户同商品唯一（UNIQUE user_id + product_id），重复添加时更新数量。注意：本表无 FOREIGN KEY 约束，user_id / product_id 为逻辑关联字段，数据完整性由业务代码保证。
字段名 类型 约束 说明
id INT PK AUTO_INCREMENT 购物车项ID
user_id INT INDEX NOT NULL 用户ID，逻辑关联 users.id（无 FOREIGN KEY；ix_cart_user_id）
product_id INT INDEX NOT NULL 商品ID，逻辑关联 products.id（无 FOREIGN KEY；ix_cart_product_id）
quantity INT NOT NULL DEFAULT 1 商品数量
unit_price DECIMAL(10,2) NOT NULL 加入购物车时商品单价快照
created_at DATETIME DEFAULT CURRENT_TIMESTAMP 加入购物车时间
唯一约束：UNIQUE(user_id, product_id) 确保同一用户对同一商品只有一条购物车记录。
快照机制：unit_price 存储下单时的商品单价，即使商品后续降价/涨价，订单金额也不受影响。
无外键说明：user_id / product_id 仅为逻辑关联字段，MySQL 数据库不配置 FOREIGN KEY，可独立 TRUNCATE / DELETE 本表，不受其他表数据影响。

orders 订单主表

TABLE

orders

订单主表，存储订单概要信息。receiver 以 JSON 格式存储收货人信息（name/phone/address）。注意：user_id 为逻辑关联字段，MySQL 不配置 FOREIGN KEY。
字段名 类型 约束 说明
id INT PK AUTO_INCREMENT 订单ID
order_no VARCHAR(32) UNIQUE INDEX NOT NULL 订单编号
user_id INT INDEX NOT NULL 用户ID，逻辑关联 users.id（无 FOREIGN KEY）
total_amount DECIMAL(10,2) NOT NULL 订单总金额（所有商品小计之和）
order_status VARCHAR(32) NOT NULL PAID / PAY_FAILED / PENDING_PAYMENT
payment_status VARCHAR(32) NOT NULL MOCK_SUCCESS / MOCK_FAILED / MOCK_PENDING
receiver JSON NOT NULL 收货人信息JSON（name, phone, address）
remark VARCHAR(200) NULL 订单备注
created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP 下单时间
JSON 字段：receiver 存储为 JSON 格式，可直接通过 JSON_EXTRACT(receiver, '$.phone') 查询收货人手机号。
无外键说明：user_id 仅为逻辑关联字段，MySQL 数据库不配置 FOREIGN KEY，可独立 TRUNCATE / DELETE 本表，不受其他表数据影响。

order_items 订单商品明细表

TABLE

order_items

订单明细表，存储每个订单包含的商品快照。下单时记录商品名称和单价，与商品表解耦。注意：order_id / product_id 为逻辑关联字段，MySQL 不配置 FOREIGN KEY。
字段名 类型 约束 说明
id INT PK AUTO_INCREMENT 订单项ID
order_id INT INDEX NOT NULL 订单ID，逻辑关联 orders.id（无 FOREIGN KEY；ix_order_items_order_id）
product_id INT INDEX NOT NULL 商品ID，逻辑关联 products.id（无 FOREIGN KEY；ix_order_items_product_id）
product_name VARCHAR(100) NOT NULL 下单时商品名称快照
quantity INT NOT NULL 购买数量
unit_price DECIMAL(10,2) NOT NULL 下单时商品单价快照
amount DECIMAL(10,2) NOT NULL 商品小计（unit_price × quantity）
快照机制：product_name 和 unit_price 在下单时从商品表复制，商品后续变更不影响历史订单。
无外键说明：order_id / product_id 仅为逻辑关联字段，MySQL 数据库不配置 FOREIGN KEY，可独立 TRUNCATE / DELETE 本表，不受其他表数据影响。

建表 SQL

MySQL 建表脚本（无外键版）

注意：本页面 SQL 示例已更新为无外键版本。完整建表脚本请参考 scripts/schema.sql。 实际执行由 app/database.py 中的 Base.metadata.create_all() 完成（无 FOREIGN KEY）。
逻辑关联说明：user_id / product_id / order_id 字段仅为业务层关联，MySQL 数据库层面不配置任何 FOREIGN KEY。 所有表均可独立 TRUNCATE / DELETE，数据完整性由业务代码保证。

CREATE DATABASE

-- 创建数据库（utf8mb4 支持完整 emoji）
CREATE DATABASE IF NOT EXISTS autoshop
  DEFAULT CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;

users（用户表）

CREATE TABLE users (
  id             INT           NOT NULL AUTO_INCREMENT COMMENT '用户ID',
  username       VARCHAR(20)   NOT NULL                COMMENT '登录用户名',
  password_hash  VARCHAR(128)  NOT NULL                COMMENT '登录密码哈希值',
  email          VARCHAR(120)  NOT NULL                COMMENT '用户邮箱',
  phone          VARCHAR(20)   DEFAULT NULL            COMMENT '手机号',
  nickname       VARCHAR(50)   DEFAULT NULL            COMMENT '用户昵称',
  created_at     DATETIME      NOT NULL                COMMENT '创建时间',
  PRIMARY KEY (id),
  UNIQUE KEY uq_username (username),
  UNIQUE KEY uq_email (email)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
  COMMENT='用户表';

products（商品表）

CREATE TABLE products (
  id          INT            NOT NULL AUTO_INCREMENT COMMENT '商品ID',
  name        VARCHAR(100)  NOT NULL                COMMENT '商品名称',
  description VARCHAR(500)  DEFAULT 'AutoShop Test Product' COMMENT '商品描述',
  category    VARCHAR(50)   NOT NULL                COMMENT '商品分类',
  price       DECIMAL(10,2) NOT NULL                COMMENT '商品单价',
  stock       INT           NOT NULL DEFAULT 0      COMMENT '当前库存数量',
  status      VARCHAR(20)   NOT NULL DEFAULT 'ON_SALE'
               COMMENT '商品状态（ON_SALE 在售 / OFF_SHELF 下架）',
  PRIMARY KEY (id),
  INDEX ix_category (category)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
  COMMENT='商品表';

cart_items（购物车明细表，无外键）

CREATE TABLE cart_items (
  id          INT            NOT NULL AUTO_INCREMENT COMMENT '购物车项ID',
  user_id     INT            NOT NULL                COMMENT '用户ID，逻辑关联 users.id',
  product_id  INT            NOT NULL                COMMENT '商品ID，逻辑关联 products.id',
  quantity    INT            NOT NULL DEFAULT 1      COMMENT '商品数量',
  unit_price  DECIMAL(10,2) NOT NULL                COMMENT '加入购物车时商品单价快照',
  created_at  DATETIME       DEFAULT NULL            COMMENT '加入购物车时间',
  PRIMARY KEY (id),
  UNIQUE KEY uq_user_product (user_id, product_id),
  INDEX ix_cart_user_id (user_id),
  INDEX ix_cart_product_id (product_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
  COMMENT='购物车明细表';

orders（订单主表，无外键）

CREATE TABLE orders (
  id              INT            NOT NULL AUTO_INCREMENT COMMENT '订单ID',
  order_no        VARCHAR(32)    NOT NULL                COMMENT '订单编号',
  user_id         INT            NOT NULL                COMMENT '用户ID，逻辑关联 users.id',
  total_amount    DECIMAL(10,2) NOT NULL                COMMENT '订单总金额',
  order_status    VARCHAR(32)    NOT NULL                COMMENT '订单状态（PAID / PAY_FAILED / PENDING_PAYMENT）',
  payment_status  VARCHAR(32)    NOT NULL                COMMENT 'Mock支付状态（MOCK_SUCCESS / MOCK_FAILED / MOCK_PENDING）',
  receiver        JSON           NOT NULL                COMMENT '收货人信息JSON',
  remark          VARCHAR(200)   DEFAULT NULL            COMMENT '订单备注',
  created_at      DATETIME       NOT NULL                COMMENT '下单时间',
  PRIMARY KEY (id),
  UNIQUE KEY uq_order_no (order_no),
  INDEX ix_orders_user_id (user_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
  COMMENT='订单主表';

order_items（订单商品明细表，无外键）

CREATE TABLE order_items (
  id           INT            NOT NULL AUTO_INCREMENT COMMENT '订单项ID',
  order_id     INT            NOT NULL                COMMENT '订单ID，逻辑关联 orders.id',
  product_id   INT            NOT NULL                COMMENT '商品ID，逻辑关联 products.id',
  product_name VARCHAR(100)   NOT NULL                COMMENT '下单时商品名称快照',
  quantity     INT            NOT NULL                COMMENT '购买数量',
  unit_price   DECIMAL(10,2) NOT NULL                COMMENT '下单时商品单价快照',
  amount       DECIMAL(10,2) NOT NULL                COMMENT '商品小计',
  PRIMARY KEY (id),
  INDEX ix_order_items_order_id (order_id),
  INDEX ix_order_items_product_id (product_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
  COMMENT='订单商品明细表';
